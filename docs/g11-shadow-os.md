# G11 Shadow Observatory in Hermes OS
The /trading page uses the current os-redesign-v1 shell. /api/os/g11-shadow is protected by the existing owner session proxy. The server connects to /autonomy-state/g11-shadow using the existing state/research key; no credentials enter browser responses.
The existing authenticated VPS state service invokes ops/g11_shadow_snapshot.py with the Stocks virtualenv. Its fixed runtime path is the active G11 checkout. The exporter checks accounting fingerprints before and after reading without contending with the execution lock, and verifies the observation chain, latest checkpoint, portfolio content hash, journal and research source bindings before responding. Invalid/busy evidence returns 503; the browser clears its data. GET requests never invoke research, place orders or initialize accounting.
Fresh daemon and projection timestamps are distinct from the last paper cycle. Research older than six hours is labeled stale. Missing metrics stay unavailable. The first observation is HOLD with simulated USD 100000 cash; this is not validated performance. Evaluation requires at least 20 observations spanning 28 days.
