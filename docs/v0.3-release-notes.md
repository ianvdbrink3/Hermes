# Hermes Investment OS v0.3 — Brain Studio

Brain Studio introduces a controlled intelligence-development workspace inside Hermes Investment OS.

The release deliberately stops at the research/control-plane boundary. It can inspect the production brain through deterministic read endpoints and can run self-improvement research only through an explicitly isolated `his-research` profile. It cannot alter production, build skills, approve changes, promote candidates, change risk limits, or execute broker actions.

This release establishes the domain and security boundaries needed for the next phase: objective experiment/evaluation infrastructure with durable evidence.
